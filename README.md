# -各位老师、同学们，大家好：

今天我要向大家介绍我们的实训项目，题目是 《基于OpenCV及ANN的数字与人像记录分析系统》。

首先，我来介绍一下项目的研究背景。
随着人工智能和计算机视觉的发展，如何高效、准确地从图像与视频中提取关键信息，已经成为实验室记录、图书馆档案管理以及公共场所安防监控中的重要需求。我们的系统正是面向这些场景，利用摄像头自动完成 人像与数字信息的采集、识别与记录，从而减少人工干预，提高工作效率。

接下来，我想介绍系统的主要功能模块。

第一，图像与视频采集模块。
我们使用 OpenCV 调用 USB 或 IP 摄像头，支持 RTSP 视频流输入，同时可以根据场景调整分辨率和帧率，并通过自动曝光和白平衡提升图像质量。

第二，人像检测与识别模块。
我们采用了 HOG + SVM 和 CNN 两种方式来做人脸检测，兼顾了速度与精度。同时基于 dlib 库进行人脸关键点定位，支持表情与姿态分析。在识别方面，我们使用 Triplet Loss 训练模型，可以对已知人员进行身份确认，对陌生人发出报警。

第三，数字识别模块。
对于印刷体数字，我们结合 OpenCV 轮廓检测和 Tesseract OCR 来实现高精度识别；而对于手写数字，我们基于 KNN 模型，在 MNIST 数据集上的测试准确率达到了 98.2%。这一模块可以应用在仪表盘读数、屏幕信息采集以及车牌识别等复杂背景下。

第四，实时显示与记录模块。
我们搭建了轻量级的 Flask Web 服务，能够提供实时视频流，并把识别到的人脸 ID、数字内容和时间戳叠加在画面上，同时写入 SQLite 数据库，方便后续的查询和导出。

最后，系统优化与部署。
我们在训练过程中采用了数据增强、模型量化和剪枝等方法，在树莓派 4B 上的推理速度提升了 35%，为系统的轻量化部署打下了基础。同时，我们还实现了 禁止区域闯入检测，一旦有人进入禁区，系统会自动截图并记录事件。

在实训过程中，我们还完成了多项子任务，包括：

摄像头图像捕捉和人脸检测；

人脸图像采集和数据库构建；

KNN 与 CNN 在数字识别和情感分析中的应用；

以及对模型的调优和优化。

通过这些环节，我们不仅掌握了 OpenCV 和 dlib 等计算机视觉工具的使用，还深入理解了 HOG、KNN、CNN 等算法的原理与实践。

最后，我想总结一下本项目的意义。
我们的系统实现了从 图像采集 → 特征提取 → 模型识别 → 实时展示与存储 的完整流程。它不仅能在实验和学习中发挥作用，还能够推广到实际应用中，比如实验室自动记录、图书馆档案数字化，以及公共场所的安防监控。

这次实训使我们真正体会到了理论与实践结合的重要性，同时也为我们今后进一步学习和研究计算机视觉与人工智能打下了坚实的基础。

我的介绍到此结束，谢谢大家！
